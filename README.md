# Assignment 3 - Right-Angled Triangle

A Python program that accepts the three sides of a triangle and checks whether the triangle is right-angled.

The program uses the Pythagorean theorem:

a² + b² = c²

Concepts used:
- Functions
- Lists
- Sorting
- Conditional statements

# Assignment 4 - Matrix Addition

Concepts used:
- Lists

- for loops

# Assignment 5 - PAN Number Validation

A Python program that validates a PAN number using a regular expression.

The expected PAN format is:

ABCDE1234F

where:
- The first five characters are uppercase letters
- The next four characters are digits
- The last character is an uppercase letter

Concepts used:
- Regular expressions
- String handling
- Conditional statements
